## Project Overview
This project is an educational mini-blockchain prototype built in Python. It demonstrates the core mechanics of a blockchain, including block creation, cryptographic hashing (SHA-256), a configurable Proof-of-Work (mining) mechanism, and the chaining of blocks via `previousHash`. It also includes a validation function to prove that historical data tampering can be successfully detected.
